### 정책 준비와 승인 경계

Attempt4 가이드에 Draft 대비 필드별 변경, 실제 승인일과 범위·위험 수락 요건, 최종 파일
생성·바이트 SHA-256 계산, 단일 활성 슬롯 전환과 Attempt3 실행 차단, 활성화 CPU 테스트
목록을 추가했다. 현재 최종 정책 파일은 미생성이며 `ATTEMPT4_APPROVED_SHA = None`이다.
PENDING에서는 Attempt3가 코드의 기존 활성 슬롯을 차지하고, Attempt4 활성화 이후에는
Attempt4만 활성화된다. 이때 Attempt3와 앞선 세 승인은 과거 실행 경로에서 차단되며
Attempt3의 사용 이력은 `retirement_on_activation.usage_status = "UNKNOWN"`으로 보존된다.
[Attempt4 가이드](../guides/attempt4_pending_validation.md),
[승인 코드](../../experiments/runtime_smoke.py).

승인 대상은 사용자 회사 WSL에서 A100 논리적 할당 최대 1회, 자동 재할당·오류 재시도 0회,
고정 Revision의 Files/SHA → Processor → Qwen Model → Layer 5 SAE → CUDA Synthetic Hook,
Generate 0회, 추가 Qwen Forward 0회, Synthetic Hook Forward 최대 2회다. CLI 0.7.5
환경 Gate를 적용한다. 별도 명시 승인은 가중치 약 5.085GB와 부속 파일, 401 인증 갱신과
307/308 Redirect의 추가 POST, 중복·잔류 할당 및 추가 CU 차감 가능성, 비용 상한 미확정을
포함해야 한다. 승인 후 회사 WSL에서 적용할 SHA·환경·세션·CU 점검과 단일 실행 명령은
가이드에 있다.

### CPU 검증과 보존

- 저장소 격리본에 기존 집 WSL 백업의 Python 3.12.3 환경을 패키지 설치 없이 사용했다.
  `CUDA_VISIBLE_DEVICES=''`, `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`,
  `UV_NO_SYNC=1`, `UV_OFFLINE=1`을 적용했다.
- `uv run python -m unittest discover -s tests -p 'test_validation*.py'`는 61 PASS /
  0 FAIL / 0 ERROR / 0 SKIP이다. 메모리 Mock과 임시 정책 파일에서만 Attempt4 활성화,
  Attempt3 retired, 별도 Claim과 중복 거부, 환경 Gate를 검증했다.
- 임시 CPU 점검 2개가 통과했다. 고정 최종 경로에 모의 JSON이 있어도 등록 전에는 Draft
  SHA와 PENDING 계획을 사용했다. Launcher·Job·Runtime·Claim에서 실제 진입을 거부했고,
  모의 레지스트리에서 SHA가 빠진 최종 정책도 거부했다. 이미 retired된 세 ID는 새
  Ledger에서도 차단됐다. 실제 Dry-run에서 ZIP CRC와 Config·Draft·실행 코드 바이트를
  확인했다. 원격 호출·할당·Claim은 0회였다.
- 전체 `compileall` 통과. `uv run python -m unittest discover -s tests -v`는 790개
  실행, **776 PASS / 0 FAIL / 0 ERROR / 14 SKIP**이었다. SKIP은 로컬 연구 산출물
  미보유 13개와 고정 Tokenizer 캐시 미보유 1개였다. 최초 `git archive` 격리본은 Git
  메타데이터가 없어 Launcher CLI 테스트 2개에서 오류가 발생했다. 격리본에 메타데이터를
  복제해 재실행한 위 결과는 종료 코드 0이다.
- 원본 `results/` 파일 653개 및 기존 저널·승인 JSON·Config의 작업 전후 SHA-256이
  일치했다. Attempt3 승인 JSON SHA는
  `90b5ad68f4871b69d1e1625e7acc7af9dd19bba8126e055b601ab6f08c86e26e`다.
  원본에 Launcher·Runtime Claim 디렉터리나 최종 Attempt4 정책 파일이 생기지 않았다.

변경은 Attempt4 가이드의 절차 추가와 이 일지다. Colab 호출, GPU 실행, 모델·SAE 다운로드,
Git Commit·Push는 수행하지 않았다. **최종 정책 승인 준비 완료 / 실제 GPU NO-GO 유지.**
다음 단계는 사용자 명시 승인, 최종 JSON·SHA 확정, §12 검토와 CPU 활성화 검증이다.
